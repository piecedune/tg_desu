# 🎌 Desu Manga Telegram Bot

Telegram-бот для чтения манги с каталога Desu. Поиск, чтение, избранное, уведомления о новых главах.

**Стек:** aiogram 3.7.0 + SQLite + Pillow

## ✨ Возможности

- 🔍 **Поиск** — по названию, жанрам, новинки, популярное
- 📖 **Чтение** — прямо в Telegram (альбом), PDF или CBZ
- 📚 **Скачивание томов** — скачай весь том одним файлом (PDF/CBZ)
- ⭐ **Избранное** — сохраняй мангу, отслеживай прогресс
- 🔔 **Уведомления** — о новых главах любимой манги
- 🎲 **Случайная манга** — открой что-то новое
- 📤 **Поделиться** — отправь ссылку друзьям
- ✅ **История чтения** — помечает прочитанные главы
- 💾 **Кэширование** — мгновенная отправка повторных файлов
- 🛡️ **Антиспам** — защита от флуда с временным баном

## 🚀 Установка

### 1. Клонируй репозиторий
```bash
git clone https://github.com/your-username/tg_desu.git
cd tg_desu
```

### 2. Создай виртуальное окружение
```bash
python -m venv venv
venv\Scripts\activate.ps1  # Windows
# source venv/bin/activate  # Linux/Mac
```

### 3. Установи зависимости
```bash
pip install -r requirements.txt
```

### 4. Настрой переменные окружения
Создай файл `.env`:
```env
TELEGRAM_TOKEN=your-bot-token-from-botfather
DESU_BASE_URL=https://desu.uno
ADMIN_ID=your-telegram-user-id
```

### 5. Запусти бота
```bash
python src/bot.py
```

## 📁 Структура проекта

```
src/
├── bot.py              # Точка входа
├── config.py           # Конфигурация, жанры
├── keyboards.py        # Клавиатуры
├── utils.py            # Утилиты (PDF, CBZ, скачивание)
├── states.py           # FSM состояния
├── dependencies.py     # Инъекция зависимостей
├── desu_client.py      # HTTP клиент Desu API
├── favorites.py        # SQLite хранилище
├── middlewares.py      # Антиспам middleware
└── handlers/
    ├── base.py         # /start, профиль, каталог
    ├── search.py       # Поиск по жанрам/названию
    ├── manga.py        # Детали манги, главы, скачивание
    └── admin.py        # Админ: рассылка, статистика
```
